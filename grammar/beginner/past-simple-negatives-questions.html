Past Simple: Negatives and Questions

Introduction

To make past simple negatives and questions, use did. The good news: did already shows the past, so the main verb goes back to the base form.

After this lesson, you will be able to:

  • Make negatives with didn't + base verb.
  • Ask yes/no questions with Did...?
  • Ask questions like Where did you go?

1. Negative Sentences

Form: subject + didn't + base verb

When to use it: Use it to say that something didn't happen.

  1. I didn't sleep well last night.
  2. She didn't come to work today.
  3. We didn't have time for breakfast.

After didn't, use the base form: I didn't go (NOT I didn't went).

2. Yes/No Questions

Form: Did + subject + base verb...?

When to use it: Put did at the start of the question.

  1. Did you have a good weekend?
  2. Did she call you back?
  3. Did they enjoy the trip?

Short answers: Yes, I did. / No, I didn't.

3. Wh- Questions

Form: question word + did + subject + base verb...?

When to use it: Use a question word (where, what, when, who...) before did.

  1. Where did you go on holiday?
  2. What did you have for lunch?
  3. When did he start his new job?

Remember: be doesn't use did. Say Where were you? (NOT Where did you be?).

Summary: Past Simple: Negatives and Questions

Type Form Example
Negative didn't + base verb I didn't go.
Yes/no question Did + subject + base verb? Did you go?
Short answers Yes, I did. / No, I didn't. Did she call? — No, she didn't.
