Some and Any

Introduction

Use some and any when you don't say the exact number or amount. Both work with plural nouns and uncountable nouns.

After this lesson, you will be able to:

  • Use some in positive sentences.
  • Use any in negatives and questions.
  • Use some when you offer or ask for something.

1. Some in Positive Sentences

Form: some + plural noun / uncountable noun

When to use it: Use it for a number or amount that isn't exact.

  1. I bought some eggs.
  2. We need some milk.
  3. She has some good ideas.

2. Any in Negatives and Questions

Form: any + plural noun / uncountable noun

When to use it: Use it in negative sentences and in most questions.

  1. We don't have any bread.
  2. Are there any shops near the hotel?
  3. Do you have any children?

With a singular countable noun, use a / an: Do you have a car?

3. Some in Offers and Requests

Form: Can I have some...? / Do you want some...?

When to use it: When you offer something or ask for something, use some in the question.

  1. Can I have some water, please?
  2. Do you want some cake?
  3. Can you get some milk on the way home?
