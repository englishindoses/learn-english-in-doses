Should / Shouldn't

Introduction

Use should to give advice and say what's a good idea. Use shouldn't to say what's a bad idea.

After this lesson, you will be able to:

  • Give advice with should.
  • Say something is a bad idea with shouldn't.
  • Ask for advice with Should I...?

1. Should

Form: subject + should + base verb

When to use it: Use it to say something is a good idea.

  1. You should see a doctor.
  2. We should leave early. The traffic is bad.
  3. You should try the fish here. It's great.

Should is the same for every subject, with no to: He should go (NOT he shoulds go, NOT he should to go).

2. Shouldn't

Form: subject + shouldn't + base verb

When to use it: Use it to say something is a bad idea.

  1. You shouldn't work so late.
  2. Kids shouldn't eat so many sweets.
  3. We shouldn't drive in the city centre.

3. Asking for Advice

Form: Should I / we + base verb...? / What should I + base verb...?

When to use it: Use it to ask someone what to do.

  1. Should I bring anything to the party?
  2. What should I wear to the interview?
  3. Should we book a table?

Summary: Should / Shouldn't

Type Form Example
Good idea should + verb You should rest.
Bad idea shouldn't + verb You shouldn't drink coffee at night.
Yes/no question Should I + verb? Should I call him?
Wh- question What should I + verb? What should I do?
