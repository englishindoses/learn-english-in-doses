Would Like

Introduction

Would like is a polite way to say want. You'll use it in cafés, restaurants, hotels and shops, and to invite and offer things to people.

After this lesson, you will be able to:

  • Say what you want politely with I'd like.
  • Offer and invite with Would you like...?
  • Answer offers politely.

1. I'd Like

Form: subject + would like ('d like) + noun / to + verb

When to use it: Use it to say what you want, politely.

  1. I'd like a coffee, please.
  2. I'd like to book a table for two.
  3. We'd like the bill, please.

I want can sound rude in shops and restaurants. I'd like sounds polite.

2. Offers and Invitations

Form: Would you like + noun / to + verb...?

When to use it: Use it to offer something or invite someone.

  1. Would you like a drink?
  2. Would you like to come for dinner on Friday?
  3. Would you like some help?

Do you like...? asks about things in general. Would you like...? is an offer, now.

3. Answering

Form: Yes, please. / No, thank you. / I'd love to.

When to use it: Use these short answers. They sound friendly and natural.

  1. Would you like some tea? — Yes, please.
  2. Would you like more bread? — No, thanks. I'm full.
  3. Would you like to come to the party? — I'd love to!

Summary: Would Like

Use Form Example
Ask for something I'd like + noun I'd like a tea, please.
Say what you want to do I'd like to + verb I'd like to pay by card.
Offer Would you like + noun? Would you like a drink?
Invite Would you like to + verb? Would you like to come?
Answer Yes, please. / No, thank you. / I'd love to. Would you like a biscuit? — Yes, please.
